# Joelwebs
- index.html  → sitio público
- admin.html  → editor (publica en GitHub desde el navegador)
- content/data.js → todo el contenido del sitio
- imagenes/   → logo (612999.jpg), video de fondo (612933.mp4), imágenes de planes, modelos y portafolio

Colores de toda la página: admin → "Colores de toda la página".
Precio "Planes desde ...": se calcula solo con el plan más barato (admin → Planes).

Cloudflare Pages: conecta este repo, sin comando de build, carpeta de salida "/" (o la carpeta donde esté el sitio).

Estilo: admin → "Estilo y contorno giratorio" (Clásico / Neón cristal) y velocidad del contorno LED (3 s por vuelta; 1.5 = rápido, 5 = lento).

Instalar la app: no hay botón ni archivos extra. El manifiesto se crea dentro de index.html y admin.html, y Chrome ofrece "Instalar app" / "Agregar a pantalla de inicio" desde su menú.
